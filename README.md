# دعای عهد (doaye_ahd)

## فایل‌هایی که خودتان باید اضافه کنید قبل از بیلد گرفتن

1. **assets/logo.png** — لوگوی برنامه (هم برای آیکون برنامه و هم برای اسپلش استفاده می‌شود مگر این‌که splash.png را جدا بگذارید)
2. **assets/splash.png** — تصویر اسپلش تمام‌صفحه
3. **assets/fonts/QuranFont.ttf** — یک فونت عربی به‌سبک قرآنی و رایگان/آزاد برای استفاده در اپ،
   مثلاً «Amiri Quran» یا «Scheherazade New» (هر دو زیر مجوز آزاد SIL Open Font License
   منتشر شده‌اند و آزادانه قابل استفاده در اپلیکیشن هستند). فایل دانلودی را دقیقاً با همین
   نام (`QuranFont.ttf`) در همین مسیر قرار دهید.
4. فایل‌های صوتی مداحان، همگی با فرمت **mp3**، دقیقاً با همین نام‌ها در مسیر `assets/audio/` :
   - `assets/audio/farahmand.mp3`
   - `assets/audio/mirdamad.mp3`
   - `assets/audio/meysam_kazem.mp3`
   - `assets/audio/asadi.mp3`

   اگر خواستید مداح یا نامی را عوض/اضافه کنید، هم در `pubspec.yaml` (بخش assets) و هم در
   لیست `kReciters` داخل `lib/main.dart` نام فایل را اضافه/ویرایش کنید.

## حجم برنامه
با توجه به این‌که فقط از یک فونت سبک، چند فایل mp3 با حجم معمولی (۲ تا ۳ مگابایتی هرکدام طبق
نمونه‌هایی که فرستادید) و بدون هیچ پکیج سنگین اضافه‌ای استفاده شده، حجم نهایی APK به‌طور معمول
در محدوده‌ی چند ده مگابایت خواهد بود و از ۱۰۰ مگابایت فاصله زیادی دارد.

## امضا برای انتشار در مایکت
دقیقاً مثل پروژه‌ی «ذکر شمار»، با تنظیم Secret های زیر در گیت‌هاب، ورک‌فلو به‌صورت خودکار
apk امضاشده تولید می‌کند: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
